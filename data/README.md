# Data source

Download **Online Retail II** from the [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/502/online+retail+ii) and place `online_retail_II.xlsx` in this folder. The project also accepts a CSV with equivalent columns.

The dataset contains transactions from a UK based online retailer between December 2009 and December 2011. The source is licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); cite Chen, D. (2012), *Online Retail II*, UCI Machine Learning Repository, DOI: [10.24432/C5CG6D](https://doi.org/10.24432/C5CG6D).

Raw data and generated DuckDB files are intentionally excluded from Git. The data contains customer identifiers; use only the aggregates in screenshots and public reports.
